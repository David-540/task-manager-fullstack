📌 Project Overview

This is a **full-stack task management application** built to demonstrate foundational skills in:

- Backend development with **ASP.NET Core Web API (C#)**
- RESTful API design (CRUD operations)
- Frontend development with **React**
- Version control using **Git & GitHub**

The project is designed as a **learning-focused but industry-aligned** application, following common patterns used in real-world software development.

---

##Learning Goals
This project aims to:
- Build and expose a REST API using controllers
- Understand request–response flow between frontend and backend
- Practice clean project structure and Git workflows
- Gradually integrate frontend and backend into a working full-stack system

##Backend (ASP.NET Core Web API)

### Features Implemented
- REST API using controller-based architecture
- CRUD endpoints for task management:
  - Create a task
  - Read all tasks
  - Update a task
  - Delete a task
- API testing and documentation via **Swagger**

### Technologies Used
- C#
- ASP.NET
- Swagger
